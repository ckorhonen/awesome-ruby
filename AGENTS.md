# Awesome Ruby List Instructions

`README.md` is the entire curated list and `CONTRIBUTING.md` provides its quality and contribution guidance. Add an item in its existing category and alphabetical order, retaining the `* [Name](URL) - description` list format.

There is no manifest or automated checker. Completion for a list edit is a narrow Markdown diff, a directly checked project URL, and an appropriate category; do not bulk-reorder entries or validate every external link for a one-entry change.
